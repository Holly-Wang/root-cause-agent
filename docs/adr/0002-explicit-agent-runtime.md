# 使用 Python 显式实现核心执行流程

为学习 Agent Harness 的实现原理并展示实际工程贡献，RCA V1 是独立运行的 Python 根因分析 Agent，使用 DeepSeek 大模型提供推理能力。其余 Agent 行为由本项目程序实现，包括模型请求组装与回复解析、上下文组织、分析循环、工具调度、授权检查、运行状态、资源限制、错误恢复、证据保存、报告生成和评测。

HTTP、JSON、文件和子进程等基础能力可使用 Python 标准库或通用库；模型客户端只承担通信，不托管分析循环、重试策略或工具执行。核心流程不交给现成 Agent 框架或插件运行环境，以便解释并验证每个调度和控制点。

初版通过命令行启动，从配置文件读取问题、材料、授权目录和限制；运行中展示进度，需要补充信息时在终端提问，并在同一进程内继续。该选择支持固定配置复跑与短时间演示，符合初版不包含 Web 后台和崩溃恢复的范围。

实现优先简单且完整贯通核心流程，边缘场景可后续补齐并说明限制。先完成真实模型选择取证动作、程序执行并回传结果、模型修正判断、程序检查引用并生成报告的闭环，再补齐核心运行控制与评测。具体模型版本和规模阈值保持可配置。
