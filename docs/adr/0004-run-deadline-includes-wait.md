# 总时限包含等待用户补充信息的时间

RCA V1 的一次分析运行具有从启动到停止分析的总时限，其中包括等待用户补充信息的时间。等待期间不调用模型，总计时继续；超时或取消时保存已取得的证据及未完成原因，并清理受控测试。

包含等待时间使每次运行具有明确结束边界，代价是用户回复较慢时可能在尚未继续分析前超时。补充信息限于文本或授权目录内的材料引用；需要扩大授权时，修改配置并重新启动分析。

每个许可测试在独立进程组中运行。取消、总超时或测试自身超时时，先请求终止，必要时强制结束并确认退出；无法确认时记录清理失败。分析停止后额外允许最多两秒清理宽限，期间不再发起模型或工具操作，并照实记录实际总耗时。这一宽限允许分析时限耗尽后仍进行受控清理，因此实际运行耗时可能比分析总时限多出清理时间。
