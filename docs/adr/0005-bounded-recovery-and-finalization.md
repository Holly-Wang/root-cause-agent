# 有限恢复，额度耗尽后由宿主保存已有材料

RCA V1 将运行怎样结束与诊断结论分别记录：分析完成、额度耗尽、超时、用户取消和系统失败是最终运行状态，报告可以正常完成但只得到候选原因或明确的信息缺口。测试断言失败属于故障证据；无法启动测试等工具故障单独记录，非法或越权工具请求由宿主拒绝并向模型返回原因，允许其在剩余额度内调整。

模型服务的暂时性错误最多重试一次，结构化报告格式错误或引用无效时最多给模型一次修正机会，仍无效则以系统失败结束。所有模型请求尝试，包括重试和报告修正，计入模型调用额度；所有工具请求，包括非法或被拒绝的请求，计入工具调用额度。

达到任一运行限额后，不再发起新的模型或工具操作。宿主保存已有材料与未完成原因，不额外调用模型生成结束报告，也不把无效模型报告标为分析完成。这些规则允许处理一次偶发错误，同时让恢复和结束路径遵守明确的资源上限。
