# Triage 标签映射

技能使用五个标准 triage 角色。本表将角色映射到本仓库 GitHub Issues 中使用的标签。

| Matt Pocock 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到角色时（例如“添加适合 Agent 处理的 triage 标签”），请使用本表对应的标签名称。

如果仓库采用其他标签名称，只需修改“本仓库标签”一列。
